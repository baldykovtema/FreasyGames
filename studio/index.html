КАК ПИСАТЬ КОД

Код похож на блоки Scratch, только ты пишешь их словами. Блоки внутри других блоков сдвигаются отступом (2 пробела, клавиша Tab).

1. Событие

when flag:
  say "Привет!", 2

Ещё события: when key "space":, when clicked:, when message "старт":, when clone:, when backdrop "Фон 2":

2. Циклы

forever:
  move 5
  bounce

repeat 10:
  turn 36

3. Условия

if key("right"):
  changex 5
elif key("left"):
  changex -5
else:
  say "жду..."

4. Переменные

очки = 0
очки += 1
showvar "очки"
if очки > 10 and жизни > 0:
  say "Победа!"

5. Свои блоки

define прыжок(высота):
  repeat 10:
    changey высота
  repeat 10:
    changey -высота

when key "space":
  прыжок 8

6. Сохранения в игре

рекорд = load("рекорд")
save "рекорд", очки

Горячие клавиши

Ctrl+Enter запуск · Ctrl+S сохранить · Ctrl+/ комментарий · Tab отступ · Shift+Tab убрать отступ

Комментарий начинается с #. Координаты как в Scratch: центр (0, 0), x от −240 до 240, y от −180 до 180.
