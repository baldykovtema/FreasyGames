# FreasyGames

Единый статический сайт с каталогом и двумя играми:

- `games/rcfcg/` — РЦФЦГ.
- `games/pvz/` — Растения против Зомби.

## Сохранения и аккаунты

Игры используют прежние проекты Supabase, ключи, таблицы и правила формирования логина. РЦФЦГ загружает статистику из `leaderboard`, ПВЗ — прогресс из `profiles` и бесконечные сохранения из `infinite_saves`. Вход и регистрация находятся на главной странице FreasyGames: выберите игру и используйте её существующий логин и пароль. В играх доступны только проверка сессии и загрузка профиля; гостям показывается кнопка возврата на сайт. Аккаунты двух игр не объединяются.

Для этого переноса SQL и изменение настроек Supabase не нужны. Не создавайте новые базы и не запускайте исходный SQL повторно. Проверка входа и облачного прогресса требует существующего аккаунта игрока; автоматические тесты используют имитацию базы.

На GitHub Pages старые игры и FreasyGames под доменом `baldykovtema.github.io` используют один origin, поэтому существующие ключи localStorage остаются доступными. ПВЗ также хранит незавершённую игру в `pvzBackgroundGame`. При переходе на другой домен локальные данные браузера автоматически не переносятся; облачный прогресс доступен после входа. Перед сменой домена сохраните бесконечную игру в облачный слот.

## Публикация

Разместите весь репозиторий на GitHub Pages: главная страница и обе папки `games` публикуются вместе. Сборка не нужна. Публикация происходит из ветки main.

Исходники импортированы из `baldykovtema/RCFCG-Webgame` и `baldykovtema/PVZ-Webgame` (ветки main). Будущие изменения в отдельных репозиториях не копируются автоматически.
